Dossier des images — TapAvis
============================

Carte NFC du hero (page d'accueil)
----------------------------------
L'image de la carte est attendue ici :

    image/Tapavis.webp

(Le nom du fichier est "Tapavis.webp", déjà utilisé par index.html.
 Pour la remplacer : écrase simplement ce fichier par ta nouvelle image,
 en gardant le même nom "Tapavis.webp". Formats acceptés : WebP, PNG, JPG.)

Conseils pour un rendu propre :
- Image au format paysage, idéalement proche du ratio d'une carte
  (largeur ≈ 1,5 à 1,6 × hauteur).
- Fond transparent (WebP/PNG) ou fond sombre pour s'intégrer au site.
- Poids léger (< 500 Ko) pour un chargement rapide.

Tant qu'aucune image n'est présente, un emplacement
« Déposez votre image ici » s'affiche automatiquement à la place.

Astuce : dans index.html, si ton image est recadrée, remplace
"object-contain" par "object-cover" pour remplir tout le cadre.
